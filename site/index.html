How it works

Set up your screen once. Get it back with one key.

⌃⌥1

Pick a mode

Click a layout in the menu bar or press ⌃⌥ and its number. The front window gets the biggest zone.

See it first

Hover a mode and the screen shows which app lands in each zone before anything moves.

Swap and replace

Drag a window onto the center of another zone to swap places, or bring in a new app. Drop near an edge and it simply floats.

Tabs in a zone

Hold ⌘ as you drop a window to stack it in a zone. Switch with ⌃⌥` or the tab bar on top.

Resize together

Drag the line between two windows. Every window on that line follows, so nothing overlaps.

Install

One command. About ten seconds.

Free and open source. No account, no subscription. Updates arrive with one click from the menu bar.

$ curl -fsSL https://raw.githubusercontent.com/Asm3r96/tessera/main/install.sh | bash
  1. Run the commandTessera goes to ~/Applications and starts in your menu bar.
  2. Allow AccessibilitySystem Settings › Privacy & Security › Accessibility. macOS asks once.
  3. Press ⌃⌥1When an update is out, a dot appears on the menu bar icon. Click Update.

Prefer to build it yourself? The README shows how, with only the Command Line Tools. Tessera saves no window contents. Its only network request is a daily update check, which you can turn off.
